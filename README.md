# 藻类细胞分裂谱系复原

从连续荧光帧的候选细胞斑点中，**联合选择**斑点与帧间连接，恢复一株藻细胞的
分裂谱系。计算全部在浏览器内完成，不上传任何数据。

## 生物学 / 组合模型

- 录入 **4 至 7 个**按时刻排列的帧，每帧 **2 至 8 个**唯一斑点
  （整数坐标 x/y、整数亮度）。
- 连接只允许：
  - **相邻帧**（`gap=1`）：位移 ≤ 相邻帧最大位移；
  - **跨恰好一帧漏检**（`gap=2`）：中间帧无该细胞斑点，两端直线位移
    ≤ 2 × 最大位移，受「允许漏检帧数」总额度约束。
- 一个细胞每步要么**保持为一个后代**，要么**分裂为恰两个后代**，不允许消亡。
- 每个非起始斑点**恰有一个祖先**；同一斑点不得被两支同时采用。
- 所有存活支必须从**起始斑点**出发到达末帧，末帧存活细胞数恰为设定值。
- **终端后代平衡复核**（可选，默认关闭）：启用后填写每次分裂两侧允许的
  **终帧后代数最大差值**；每个分裂母本的两名女儿须各自追溯到末帧，二者
  终帧后代数之差不得越限。跨帧漏检只延续原分支（配额单传），嵌套分裂
  计入对应女儿的完整后代子树。该约束在选择斑点、连接与分裂拓扑的同一次
  联合枚举中同步满足，而非先求原最优谱系再过滤。
- 裁决顺序（依次比较）：
  1. 采用斑点**总亮度最高**；
  2. **漏检段数最少**；
  3. **输入顺序稳定裁决**：逐帧比较采用斑点的输入序号，再比较母本编号。

因此不会逐帧贪心挑选最亮斑点而把杂质或不同个体串成同一支；高亮杂质即使
能形成极度偏斜的分裂树（如一侧 3 个终帧后代、另一侧仅 1 个），在平衡
复核启用时也不会被选中，求解器会直接在满足平衡限值的谱系中取最优。

当终帧目标数与祖先/位移/漏检约束（启用时还包括终端后代平衡限值）无法
同时满足时，编辑草稿保留，页面指出**最早断开的帧间**（如
「第 1 帧 → 第 2 帧」），并明确终帧目标与平衡限值无法同时满足。任一帧、
限制或平衡开关/限值被修改后，旧谱系立即作废并提示重新复原（草稿保留在
编辑区与浏览器 localStorage）。

复原成功且启用复核时，结果区按分裂帧逐次列出：分裂帧、两名女儿
（含所在帧与编号）及各自追溯到末帧的后代数、实际差值与限值。

## 本地运行（无需 Docker）

需要 Node.js ≥ 20（零第三方依赖）：

```bash
npm start                 # 默认 http://localhost:8080
WEB_PORT=9000 npm start   # 自定义端口
```

## Docker 运行

```bash
docker compose up web --build        # 浏览器打开 http://localhost:8080
WEB_PORT=9000 docker compose up web  # 用 .env 或环境变量自定义端口
```

网页端口完全由 `WEB_PORT` 控制（`.env` 可参考 `.env.example`）。

## verify 一次性校验服务

健康检查通过后，`verify` 服务自行执行**单元测试 → 构建 → 含分裂与漏检的谱系
烟测**，并以容器退出码报告结果：

```bash
docker compose up --build \
  --abort-on-container-exit --exit-code-from verify
echo $?    # 0 表示全部通过
```

三项也可不依赖 Docker 直接运行：

```bash
npm test     # node:test 单元测试（含 ~2000 组随机输入与独立暴力枚举对拍）
npm run build  # 语法检查 + 静态资源完整性 + 构建清单
npm run smoke  # 健康检查 / 静态资源 / 分裂+漏检谱系 / 不可行最早断帧
```

## 求解方法

带备忘的深度优先联合枚举：状态为「某帧边界上的存活斑点集合 + 正在漏检中的
母本集合 + 剩余漏检配额」，逐帧联合决定每支的保持/分裂/漏检，并在同一转移内
保证斑点不被两支共用；同一状态的最优后缀只求解一次。配合末帧目标数的增长上界
剪枝，在 4–7 帧、每帧 ≤8 斑点的规模下即时返回。不可行时通过前向可达性与
后缀可行性，定位最早没有任何可行谱系穿过的帧间。

为保证宽松平衡限值（如 7/8 目标）下的全连通输入也能即时返回，实现上还做了：

- 备忘与转移键全部为整数（按帧分桶的嵌套 Map），母本配对向量打包进单个
  整数，热路径零字符串/小数组分配；
- 独立的「后缀可行性」布尔备忘（找到任一可行后继即返回），最优枚举只进入
  确实可到达末帧的后继，彻底排除死路状态；
- 总亮度分支限界：预先计算各帧 top-k 亮度与安全后缀亮度上界，一旦本帧选点
  加上界劣于已发现最优即整条转移剪枝（同亮度时仍保留漏检更少/输入顺序更优
  的可能，裁决语义不变）；
- 边界内层 DP 同时施加计数走廊的下界与上界，部分排列无法再翻倍到末帧目标
  数时立即丢弃；分裂配额只枚举同时满足和、差值与剩余翻倍上界的整数对；
- 转移表冻结为并列类型化数组，稠密输入下的常驻内存远低于通用 Map。

启用平衡复核时，状态额外携带「各存活支 / 漏检支最终须占有的末帧后代数」
配额（根配额为终帧目标数）：保持与漏检补获原样继承母本配额，分裂时枚举
`n1 + n2 = 母本配额` 且 `|n1 − n2| ≤ 限值` 的有序整数对；末帧每支配额恰为 1。
关闭复核时配额为通配值，状态空间与结果完全退化为上述原模型。
